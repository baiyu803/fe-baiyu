
### 一、Java I/O

- `I/O` 就是输入输出

  - 比如读取硬盘上的文件、写入文件、网络文件传输、鼠标键盘输入

- JDK 提供了一套用于 IO 操作的框架

  - 一个像水流一样，根据流的传输方向和读取单位，分为字节流 `InputStream`、`OutputStream` 以及字符流 `Reader`、`Writer`的 IO 框架

  - 字节流一次读取一个字节，也就是一个 byte 的大小，而字符流顾名思义，就是一次读取一个字符，也就是一个 char 的大小

- 这里的 Stream 并不是前面集合框架认识的 Stream，这里的流指的是**数据流**

- 通过流，可以从流中读取数据，直到流为空；或者不断向流中写入数据，直到写入完成


### 二、文件字节流

- 在 Java IO 体系中，**字节流**以单个字节（byte）为最小单位进行数据读写，是所有流的底层基础，天生适合处理**图片、音频、视频、压缩包等二进制**文件，也可用于文本文件（但存在编码乱码风险）

- 核心实现类是

  - `FileInputStream`：文件字节输入流，用于从文件读取字节数据

  - `FileOutputStream`：文件字节输出流，用于向文件写入字节数据

#### 2.1 FileInputStream

- 核心读取方法

| 方法签名 | 功能说明 | 返回值说明 |
| --- | --- | --- |
| `int read()` | 读取1 个字节 | 返回读取到的字节值（范围 0~255）；读到文件末尾返回 -1 |
| `int read(byte[] buf)` | 批量读取字节到数组 | 返回本次实际读取到的字节数；读到末尾返回 -1 |
| `int read(byte[] buf, int off, int len)` | 读取 len 个字节到数组的指定偏移位置 | 返回实际读取字节数；末尾返回 -1 |
| `void close()` | 关闭流，释放操作系统资源 | - |

- 看两个 demo

::: code-group
```java [单个字节读取]
import java.io.FileInputStream;
import java.io.IOException;

public class ReadDemo {
    public static void main(String[] args) {
        // try-with-resources 自动关闭流，Java 7+ 推荐写法
        try (FileInputStream fis = new FileInputStream("test.txt")) {
            int b;
            // 循环读取，返回 -1 表示文件读取完毕
            while ((b = fis.read()) != -1) {
                System.out.print((char) b); // 仅英文可正常转字符
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```
```java [字节数组批量读取]
try (FileInputStream fis = new FileInputStream("test.txt")) {
    // 定义缓冲区，通常设为 1024 的整数倍，常用 8KB
    byte[] buf = new byte[1024 * 8];
    int len; // 每次实际读取的字节数
    while ((len = fis.read(buf)) != -1) {
        // 只转有效长度的字节为字符串（中文仍可能乱码）
        String str = new String(buf, 0, len);
        System.out.print(str);
    }
} catch (IOException e) {
    e.printStackTrace();
}
```
:::

- 实际上上面是简写形式，下面是完整的

```java
public static void main(String[] args) {
    FileInputStream inputStream = null;    // 定义可以先放在try外部
    try {
        inputStream = new FileInputStream("路径");
        int b;
        // 循环读取，返回 -1 表示文件读取完毕
        while ((b = inputStream.read()) != -1) {
            System.out.print((char) b); // 仅英文可正常转字符
        }
    } catch (FileNotFoundException e) {
        e.printStackTrace();
    } finally {
        try {    // 建议在finally中进行，因为关闭流是任何情况都必须要执行的！
            if(inputStream != null) inputStream.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

- 但一般不建议这样写，因为 `try-with-resources` 自动关闭流是 Java 7+ 推荐写法，可以避免手动关闭流的麻烦

#### 2.2 FileOutputStream


- 核心写入方法

| 方法签名 | 功能说明 |
| --- | --- |
| `void write(int b)` | 写入1 个字节 |
| `void write(byte[] buf)` | 写入整个字节数组 |
| `void write(byte[] buf, int off, int len)` | 写入数组中从 off 开始的 len 个字节 |
| `void flush()` | 刷新缓冲区（基础文件字节流无内置缓冲区，作用有限） |
| `void close()` | 关闭流，释放资源 |

```java
import java.io.FileOutputStream;
import java.io.IOException;

public class WriteDemo {
    public static void main(String[] args) {
        // 第二个参数 true = 追加写入；不写默认覆盖
        try (FileOutputStream fos = new FileOutputStream("output.txt", true)) {
            // 1. 写入单个字节
            fos.write(97); // 写入字符 'a'

            // 2. 写入完整字节数组
            String content = "Hello 字节流";
            byte[] bytes = content.getBytes(); // 字符串转字节（默认平台编码）
            fos.write(bytes);

            // 3. 写入数组的一部分
            fos.write(bytes, 0, 5); // 只写入前 5 个字节 "Hello"

        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

::: info
- 字节流最典型的应用是文件复制，尤其适合图片、视频等二进制文件

```java
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;

public class FileCopy {
    public static void main(String[] args) {
        String src = "source.jpg";   // 源文件
        String dest = "target.jpg";  // 目标文件

        try (
            FileInputStream fis = new FileInputStream(src);
            FileOutputStream fos = new FileOutputStream(dest)
        ) {
            byte[] buf = new byte[1024 * 8]; // 8KB 缓冲区
            int len;
            // 边读边写
            while ((len = fis.read(buf)) != -1) {
                fos.write(buf, 0, len);
            }
            System.out.println("文件复制完成");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```
:::

### 三、文件字符流

- 字符流不同于字节，字符流是以一个具体的字符 char (2 字节)进行读取，因此它只适合读纯文本的文件

  - 自动处理编码转换，解决字节流中文乱码问题

  - 不能处理图片、视频、压缩包等二进制文件

- 核心实现类

  - `FileReader`：文件字符输入流，读取文本文件，父类 Reader

  - `FileWriter`：文件字符输出流，写入文本文件，父类 Writer

- 使用方法和字节流类似，不需要重新介绍

```java
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;

public class TextCopy {
    public static void main(String[] args) {
        try(
                FileReader fr = new FileReader("source.txt");
                FileWriter fw = new FileWriter("target.txt")
        ){
            char[] buf = new char[1024];
            int len;
            while((len = fr.read(buf)) != -1){
                fw.write(buf,0,len);
            }
            System.out.println("文本复制完成");
        }catch (IOException e){
            e.printStackTrace();
        }
    }
}
```

### 四、文件工具类

- `java.nio.file` 是一个静态类，提供了文件操作的静态方法，如复制、移动、删除等。

- 需要配合 `Path`（文件路径对象）来使用

```java
import java.nio.file.Path;
import java.nio.file.Paths;

public class FileTest {
    public static void main(String[] args) throws Exception {
        // 1. 相对路径
        Path path = Paths.get("demo.txt");
        // 2. 多级路径拼接（自动适配系统分隔符 / \）
        Path dir = Paths.get("D", "java", "file");
        // 3. 绝对路径
        Path absPath = Paths.get("D:/java/demo.txt");
    }
}
```

- Files 常用来文件目录判断、文件操作等

```java
Path path = Paths.get("demo.txt");

Files.exists(path);          // 文件/文件夹是否存在
Files.isRegularFile(path);   // 是否普通文件（不是文件夹）
Files.isDirectory(path);     // 是否文件夹
Files.isReadable(path);      // 是否可读
Files.isWritable(path);      // 是否可写
Files.isHidden(path);        // 是否隐藏文件

// 创建空文件，文件已存在会抛异常
Files.createFile(Paths.get("new.txt"));

// 创建单层文件夹，上级目录不存在报错
Files.createDirectory(Paths.get("testDir"));

// 创建多级目录（最常用，自动创建所有父文件夹）
Files.createDirectories(Paths.get("a/b/c"));

// 删除，文件不存在直接抛异常
Files.delete(path);

// 推荐：不存在不报错，安全删除
Files.deleteIfExists(path);
```

### 五、缓冲流

- 缓冲流属于装饰流，不直接操作文件，包装原始字节 / 字符流，内置内存缓冲区，减少磁盘 IO 次数，大幅提升读写性能

- 分为两大类：字节缓冲流、字符缓冲流

- 字节缓冲流（处理二进制：图片、视频、压缩包）

  - `BufferedInputStream`：缓冲字节输入流，包装 `FileInputStream`
  - `BufferedOutputStream`：缓冲字节输出流，包装 `FileOutputStream`


- 字符缓冲流（只处理文本文件）

  - `BufferedReader`：缓冲字符输入流，包装 `FileReader`/ 转换流`，独有 readLine() 按行读取
  - `BufferedWriter`：缓冲字符输出流，包装 `FileWriter`/ 转换流`，独有 newLine() 跨平台换行


```java
try (
        BufferedInputStream bis = new BufferedInputStream(new FileInputStream("source.mp4"));
        BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("target.mp4"))
) {
    byte[] buffer = new byte[1024 * 8];
    int length;
    while ((length = bis.read(buffer)) != -1) {
        bos.write(buffer, 0, length);
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

> 其实就是套了一个缓冲区，方法都差不多

### 六、转换流

- 两个核心类

  - `InputStreamReader`：字节流转字符流，包装 `FileInputStream` （字节流），把字节 → 字符，可指定编码读取文本

  - `OutputStreamWriter`：字符流转字节流，包装 `FileOutputStream`（字节流），把字符 → 字节，可指定编码写入文本

::: tip
- 字节流只操作 byte，字符流操作 char
- 文件存储永远是字节，读写文本时需要编码 / 解码
- `FileReader` / `FileWriter` 缺陷：只能用系统默认编码（Windows GBK、Linux/Mac UTF-8），跨平台乱码

- **转换流就是用来手动指定编码，解决乱码问题**
:::

- 结构图解

  - 读取文件：磁盘字节 → `FileInputStream` → `InputStreamReader` (指定 UTF-8) → `BufferedReader`

  - 写入文件：`BufferedWriter` → `OutputStreamWriter` (指定 UTF-8) → `FileOutputStream` → 磁盘字节


::: code-group
```java [读取]
import java.io.*;

public class TransRead {
    public static void main(String[] args) throws IOException {
        // 字节流 + 转换流指定编码 + 缓冲流（按行读）
        try (BufferedReader br = new BufferedReader(
                new InputStreamReader(new FileInputStream("test.txt"), "UTF-8")
        )) {
            String line;
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }
        }
    }
}
```
```java [写入]
try (BufferedWriter bw = new BufferedWriter(
        new OutputStreamWriter(new FileOutputStream("out.txt"), "UTF-8")
)) {
    bw.write("中文不乱码");
    bw.newLine();
}
```
:::

- 和 `FileReader` / `FileWriter` 对比，指定编码，解决乱码问题，跨平台兼容

```java
// 缺陷：跟随系统编码，Windows打开中文乱码
BufferedReader br = new BufferedReader(new FileReader("test.txt"));

// 推荐：强制UTF-8，全平台统一
BufferedReader br = new BufferedReader(new InputStreamReader(new FileInputStream("test.txt"), "UTF-8"));
```

### 七、打印流

- 专门简化输出的包装流，自带格式化打印、自动换行、自动刷新，不会抛 IO 异常（只吞异常）

- `PrintStream`：字节打印流，System.out 本质就是它

- `PrintWriter`：字符打印流，推荐（支持字符编码，无乱码）

::: code-group
```java [PrintStream]
public static void main(String[] args) {
    try(PrintStream stream = new PrintStream(new FileOutputStream("test.txt"))){
        stream.println("lbwnb");   //其实System.out就是一个PrintStream
    }catch (IOException e){
        e.printStackTrace();
    }
}
```
```java [PrintWriter]
// 文件打印，UTF-8 不乱码
try (PrintWriter pw = new PrintWriter(new OutputStreamWriter(new FileOutputStream("log.txt"),"UTF-8"))) {
    pw.println("用户登录成功");
    pw.printf("用户名：%s，时间：%s%n", "zhangsan", System.currentTimeMillis());
    pw.flush();
}
```
:::
